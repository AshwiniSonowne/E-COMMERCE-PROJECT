# 🛒 E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes an e-commerce dataset to understand sales performance, customer behavior, payment patterns, product performance, delivery time, and customer reviews.

The project uses **SQL, Power BI, and Tableau** to transform raw e-commerce data into meaningful business insights and interactive dashboards.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze e-commerce sales and payment performance
- Compare weekday and weekend payment statistics
- Analyze customer reviews and payment methods
- Measure delivery and shipping performance
- Analyze sales and customer activity by city
- Understand the relationship between shipping time and review scores
- Identify top-performing product categories
- Create interactive dashboards for business reporting

---

## 🗂️ Dataset

The project is based on the **Brazilian E-Commerce Public Dataset by Olist**.

The dataset contains information related to:

- Orders
- Customers
- Products
- Payments
- Reviews
- Order Items

### Key Columns Used

- `order_id`
- `customer_id`
- `order_purchase_timestamp`
- `order_delivered_customer_date`
- `payment_type`
- `payment_value`
- `price`
- `customer_city`
- `review_score`
- `product_category_name`

## 📊 Key KPIs & Analysis

### 1. Weekday vs Weekend Payment Statistics
Analyzed payment performance based on the day of the week using the order purchase timestamp.

### 2. Review Score 5 & Credit Card Orders
Identified the number of orders that received a review score of 5 and were paid using a credit card.

### 3. Average Delivery Days – Pet Shop
Calculated the average number of days taken to deliver orders belonging to the `pet_shop` category.

### 4. São Paulo Customer Analysis
Calculated average order price and payment values for customers from São Paulo.

### 5. Shipping Days vs Review Score
Analyzed the relationship between shipping/delivery time and customer review scores.

### 6. Product Category Performance
Analyzed product categories based on sales and order performance to identify high-performing categories.
